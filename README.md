# Marwan OS — إصلاح تشغيل GitHub Pages

فك ضغط الملف، وارفع **محتوياته** إلى جذر المستودع؛ يجب أن يكون `index.html` بجوار `config.js` وبقية ملفات JavaScript وCSS، وليس داخل مجلد إضافي.

من Settings → Pages اختر Deploy from a branch ثم `main` و `/(root)` ثم Save. لا تحتاج إلى npm أو خطوة بناء. إذا كان الموقع مثبتًا سابقًا وظهرت النسخة القديمة، امسح بيانات الموقع مرة واحدة ثم افتحه مجددًا.

## الإصلاح

- وضع JavaScript في المسارات التي تطلبها الصفحة وإضافة مكتبة Supabase 2.117.3 محليًا، دون الاعتماد على CDN أثناء التشغيل.
- إضافة تنسيق عربي متجاوب بديل؛ ملف التصميم الأصلي لم يكن ضمن المرفقات.
- إظهار خطأ مفهوم عند فشل تحميل ملفات التشغيل.
- إضافة service worker لتخزين ملفات الواجهة فقط، دون بيانات حساب Supabase. الحفظ والمزامنة يحتاجان الإنترنت.
- توفير عارض PDF أصلي للقراءة والتنزيل. التعليقات على PDF ليست منفذة هنا؛ ملف العارض الأصلي لم يكن مرفقًا.

## الخادم

احتُفظ بإعدادات مشروع Supabase الموجودة في config.js. إصلاح الواجهة لا ينشئ المشروع أو الجداول ولا ينشر الوظائف على الخادم.
ملفات SQL الأصلية موجودة تحت supabase/migrations، ووظيفة الذكاء الاصطناعي الأصلية تحت supabase/functions/marwan-ai/index.ts. إذا لم تكن مهيأة سابقًا، يلزم إعدادها في Supabase. لا تنفذ SQL مجددًا على قاعدة قائمة دون مراجعة.
أضف رابط GitHub Pages إلى روابط إعادة التوجيه المسموحة في إعدادات Authentication عند استخدام تأكيد البريد أو استعادة كلمة المرور.

## الاختبارات

`node --test tests/domain.test.mjs`

تشغيل محلي: `python3 -m http.server 8000` ثم افتح http://localhost:8000.

مكتبة Supabase موزعة بترخيص MIT؛ انظر supabase-LICENSE.txt.

## الدخول بالرمز — تحديث الحسابات

- إنشاء الحساب بالبريد وكلمة المرور يتم عبر وظيفة `access-code-auth` دون إرسال بريد تحقق.
- يظهر رمز عشوائي من 256 بت مرة واحدة. بعد حفظه يستخدم الرمز وحده للدخول. لا ترسله لأحد.
- كلمة المرور التي اخترتها وسيلة احتياطية لإصدار رمز جديد. إصدار رمز جديد يلغي الرمز السابق، ولا ينهي الجلسات المفتوحة مسبقًا.
- من الإعدادات يمكن إصدار رمز جديد.
- حسابات البريد الموجودة سابقًا تحتفظ ببياناتها؛ يمكن الدخول بالبريد وكلمة المرور لإصدار رمز.
- إن فُقد الرمز وكلمة المرور معًا فلا توجد استعادة آلية دون إثبات ملكية مناسب.
- تسجيل Google أزيل من الواجهة. الإعداد العام لخدمة البريد لم يُغيّر؛ التسجيل الجديد في هذا التطبيق لا يستدعي إرسال البريد أصلًا.

وظيفة الخادم تستخدم مفاتيح Supabase الخاصة من متغيرات البيئة تلقائيًا، ولا توجد مفاتيح إدارية في ملفات الواجهة. بصمات SHA-256 محفوظة في جدول محمي من جميع عملاء المتصفح، مع تحديد محاولات على الخادم. الوظيفة العامة تتحقق بنفسها من رمز الدخول أو JWT عند إصدار رمز جديد.

تعريف SQL المنفذ في `supabase/access-code-auth.sql`، ومصدر الوظيفة في `supabase/functions/access-code-auth/index.ts`. لا تعِد تنفيذ إنشاء الجداول على المشروع القائم.

## مفاتيح الذكاء الاصطناعي من الإعدادات

أدخل مفتاح API في الإعدادات واضغط «التحقق وحفظ المفتاح». يُكتشف Claude أو Gemini من صيغة المفتاح ثم يُتحقق منه لدى المزوّد بقراءة قائمة النماذج، دون طلب توليد مدفوع. المفتاح يُحفظ مشفّرًا داخل Supabase Vault لحساب المستخدم فقط، ولا يعود إلى المتصفح كاملًا. لا تُحفظ المفاتيح في localStorage أو preferences أو المستودع.

Claude يختار Haiku 5.5 تلقائيًا إذا كان متاحًا. Gemini يتيح الاختيار بين 3.5 Flash-Lite و3.8 Flash، ثم حفظ الإعدادات. النماذج غير المتاحة للمفتاح تظهر معطلة، ولا يتم الاستبدال بنموذج آخر. يمكن حذف المفتاح أو استبداله؛ يوجد مفتاح نشط واحد لكل حساب.

مسار المحادثة يستخدم مفتاح المستخدم المحفوظ، بدل متغيرات ANTHROPIC_API_KEY وGEMINI_API_KEY العامة. تعريف التخزين والدوال في `supabase/ai-provider-keys.sql`. يتضمن trigger خاصًا لتنظيف السر المشفّر عند حذف سجل المفتاح أو حساب المستخدم. القراءة والحفظ والحذف لا تتاح إلا لخدمة الخادم، بعد تحقق الوظيفة من JWT المستخدم.

الاختبارات: `node --test tests/*.test.mjs`. اختبارات قائمة المزوّدين الناجحة تستخدم استجابات محاكاة معلنة، بينما اختبار رفض المفاتيح غير الصحيحة يُنفّذ على الخدمة الحقيقية. لم تُنفَّذ إجابة مدفوعة دون مفتاح API صالح يقدمه المستخدم من داخل التطبيق.

## الواجهات المبسطة

الرئيسية شاشة لفتح التطبيقات؛ تظهر أول ستة تطبيقات، والبقية تحت «كل التطبيقات». ترتيب التطبيقات والأسماء والمجلدات والبطاقات المحفوظة تبقى كما هي. يظهر ملخص اليوم عند فتح «نظرة سريعة».

كل تطبيق يفتح بشاشة كاملة، بعنوانه ولونه وزر العودة للتطبيقات، دون قائمة جانبية أو شريط بحث مشترك. يمكن فتحه مباشرة عبر `#/tasks` أو `#/notes` أو غيرهما، ويعمل رجوع وتقدم المتصفح.

المحرر يظهر حقول التطبيق الأساسية؛ التكرار والأولوية والروابط والمرفقات متاحة في خيارات مطوية، وتُحفظ قيمها عند التعديل. المصروفات تُكتب كمبلغ موجب مع اختيار «مصروف» بدل إدخال رقم سالب. التقويم على الجوال يبدأ بعرض اليوم. إعدادات الاسم والمظهر وصلاحيات المساعد متاحة ضمن أقسام مطوية.

اختُبرت الشاشات الـ15 على عرضي 390 و1440 بكسل باستخدام حساب مؤقت وخادم Supabase الحقيقي، دون إرسال طلبات AI مدفوعة.
